# 优衣库零售门店销售数据多维分析与策略洞察
## 项目背景
本项目基于优衣库约 2 万条零售销售数据，利用 Python 进行数据清洗、探索性数据分析（EDA）以及统计学假设检验。项目旨在通过多维度剖析客群特征、城市差异、渠道表现及产品结构，识别驱动利润的关键变量，并为零售业务优化提供数据支撑和策略建议。

## 技术栈
数据处理：Pandas, Numpy

数据可视化：Matplotlib, Seaborn (支持 SimHei 中文字体)

统计检验：Scipy, Statsmodels (主要应用 Welch's T-test)

## 项目结构
Uniqlo_Data_Analysis.ipynb：包含数据清洗、可视化分析、统计检验及结论的完整代码。

优衣库.xls：项目原始数据集。

cleaned_data_uniqlo.csv：清洗后的高质量数据集。

README.md：项目说明文档。

## 核心分析模块
1. 数据处理与清洗
识别并处理 134 行缺失值。

剔除重复记录，保障分析样本的一致性。

衍生变量构建：价格区间分段、时间类别（周中/周末）、单笔利润。

2. 探索性数据分析 (EDA)
客群画像：分析不同性别、年龄段（20-39岁为核心）在各渠道的购买偏好。

城市效率：衡量不同城市门店的利润表现，通过“单笔利润”指标排除流量干扰。

产品维度：识别不同渠道的热销类目，发现基础款（T恤等）的核心驱动作用。

时间维度：对比工作日与周末的销售波动，揭示消费者的目的性购买特征。

3. 统计假设检验
核心分析：运用双样本 T-检验（Welch's T-test）对比线上与线下渠道的单笔利润差异。

初步检验：全量数据下线上平均单笔利润（44.09元）显著高于线下（41.67元）。

深度控制：在细分用户画像维度下进行检验，发现 P-value 为 0.4883，即控制变量后渠道间利润无显著差异。

结论：利润差异的核心驱动因素在于高价值用户结构的占比，而非渠道本身。

## 业务洞察与建议
强化高价值女性客群运营：针对 20-39 岁女性核心客群建立分层会员体系，实施个性化推荐。

优化时间维度运营：工作日订单量显著高于周末，应加强周中库存周转与高频时段推送。

基础款驱动策略：线上线下热销产品高度一致，应持续优化 T恤 等核心基础款的供应链效率。

提升配件利润贡献：配件类商品单笔利润表现突出，建议在陈列和推荐逻辑中加大“服装+配件”的连带销售。

全渠道协同：线下侧重服务体验，线上侧重便捷性与算法精准推荐。
